# AmurTrans Assistant

Telegram-помощник проекта «АмурТранс Контроль». Бот помогает собрать заявку на перевозку по обязательным полям, показывает недостающие сведения и ведёт к Wiki проекта. Учебный прототип не назначает цену, перевозчика или статус реального заказа.

## Команды

- `/start` — краткое знакомство и подсказка про `/help`;
- `/new` — начать пошаговый диалог заявки;
- `/example` — демонстрационный пример;
- `/wiki` — документация продукта;
- `/dashboard` — открывает интерактивный дашборд на Vercel;
- `/confirm` — подтвердить собранный черновик;
- `/cancel` — отменить текущий диалог;
- `/help` — инструкция.

После `/new` бот спрашивает поля по очереди и повторяет запрос только для поля с ошибкой. Повторно отправлять всю форму не нужно. В конце бот показывает сводку и ждёт `/confirm`. При наличии Upstash Redis черновик хранится в общем хранилище с TTL 30 минут и доступен разным экземплярам функции; локально без этих переменных используется память процесса. Для Redis задаются `KV_REST_API_URL` и `KV_REST_API_TOKEN` (или `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`). В production надёжное продолжение диалога включено только после подключения постоянного хранилища. Подтверждение отмечает только учебный черновик: рабочая система обработки не подключена.

## Запуск и публикация

Нужен Python 3.12. Для локальной проверки логики выполните `python -m unittest discover -s tests`.

На Vercel импортируйте этот репозиторий как Python-проект. Установите переменные окружения `TELEGRAM_BOT_TOKEN` и `TELEGRAM_WEBHOOK_SECRET`, подключите Upstash Redis и проверьте наличие `KV_REST_API_URL` и `KV_REST_API_TOKEN`. Функция webhook находится по адресу `/api/webhook`; её GET-проверка показывает тип активного хранилища без раскрытия секретов. После публикации вызовите `setWebhook` Telegram Bot API с адресом `https://<deployment>/api/webhook` и тем же секретом. Секреты не записывайте в Git.

Bot API используется напрямую через стандартную библиотеку Python. Не нужен пользовательский Telegram-сеанс и код входа в аккаунт.
